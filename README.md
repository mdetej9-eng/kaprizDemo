# Салон-парикмахерская «Каприз» — сайт-визитка

Одностраничный сайт-визитка для салона-парикмахерской «Каприз» (г. Ставрополь, пр. Кулакова, 27д).

## Что внутри

- **Герой-секция** с графиком работы (8:00–20:00) и кнопкой звонка
- **Услуги**: стрижки, окрашивание, маникюр
- **О салоне** с фото входа, фактами и ссылкой на 2ГИС
- **Галерея работ** с лайтбоксом (8 фото стрижек и окрашиваний)
- **Контакты**: адрес, телефон, маршрут, карточка 2ГИС

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.
Шрифты: Playfair Display + Montserrat (Google Fonts).
Палитра: слива, золото, крем.

## Структура

```
├── index.html      — разметка
├── css/style.css   — стили и адаптив
├── js/main.js      — меню, анимации, лайтбокс
└── img/            — фото салона и работ
```

## Запуск

Просто откройте `index.html` в браузере, либо опубликуйте через GitHub Pages.

## Данные

Телефон, адрес, график и рейтинг — из карточки 2ГИС (рейтинг 3.7, 15 отзывов).
Фотографии — из карточки салона в 2ГИС.
